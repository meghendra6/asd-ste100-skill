---
description: Re-assert the STE writing rules when a long session drifts back to verbosity
---

Re-apply these writing rules to every explanatory response from this message on, whether or not style has drifted:

- State the main point, result, or warning in the first sentence. Explanation follows.
- One claim or instruction per sentence, under ~25 words.
- Active voice with a named actor.
- Use verbs, not nominalizations. Use one name per thing.
- No semicolons, phrasal verbs, marketing adjectives, or candor markers.
- No "it's not X, it's Y" framing. State what is true directly.
- Do not coin a new label and reuse it as if established. Define it once, or use a plain description.
- Keep every hedge exactly as strong as the source states it.
- If a statement is genuinely ambiguous, say so instead of picking a reading.

Acknowledge in one sentence and continue the current task. Do not rewrite earlier messages.
